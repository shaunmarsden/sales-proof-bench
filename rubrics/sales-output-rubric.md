# Sales Output Rubric

Score each area from 0 to 5. An output with an invented customer commitment, unapproved commercial claim or unsafe information handling fails automatically regardless of its total.

| Area | A high score means |
| --- | --- |
| Factual accuracy | Every claim matches the supplied source |
| Evidence fidelity | The result uses the important context and preserves meaningful uncertainty |
| Fact separation | Facts, assumptions, estimates and suggestions are visibly different |
| Commercial usefulness | The output helps a sensible next conversation or action |
| Next step clarity | Actions are specific, owned and do not pretend to be agreed |
| Tone | Direct, clear and appropriate for the audience |
| Privacy | No unnecessary sensitive information appears |
| Approval discipline | A person remains responsible for messages, commitments and system changes |
| Hallucination risk | The output resists filling gaps with plausible detail |

## Write a Short Verdict

After scoring, write:

- what the output got right;
- what needed correction;
- what a salesperson could use;
- what a salesperson must not use without changing; and
- what this one test cannot prove.
